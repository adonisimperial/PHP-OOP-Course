# 🐘 PHP Object-Oriented Programming (OOP) Course

Welcome to the official code repository for the PHP OOP course. This curriculum was originally developed and delivered while teaching Object Oriented Programming class as part of my part-time as an instructor at **CACT College**. 

This repository is designed to bridge the gap between procedural programming and modern, structured, and professional backend development using PHP.

---

## 🎯 Course Objective
The primary goal of this resource is to help students transition seamlessly from procedural PHP to **Object-Oriented Programming (OOP)**. By the end of this track, learners will understand how to build reusable, maintainable, and industry-standard applications.

---

## 📚 Curriculum Breakdown

The source code and exercises are organized by topic to support a step-by-step learning journey:

* **`lesson1-2/`** — PHP basics.
* **`lesson3/`** — Control structure and arrays.
* **`lesson4/`** — Functions.
* **`lesson4v2`** — Functions - class activity.
* **`prelim_exam/`** — Preliminary assessment.

## 🛠️ Getting Started for Students & Learners

To run these examples locally on your computer, follow these simple steps:

### 1. Prerequisites
Make sure you have a local PHP server environment and a code editor installed:
* **Laragon** (Recommended) or **XAMPP**
* **Visual Studio Code**

### 2. Clone the Repository
Open your terminal (or Laragon's built-in Terminal) and navigate to your server's root folder, then clone the repository:

* **If using Laragon:** Navigate to `C:\laragon\www\`
* **If using XAMPP:** Navigate to `C:\xampp\htdocs\`

Run the following command:
```bash
git clone https://github.com
```
*(Remember to replace `YOUR_GITHUB_USERNAME` with your actual GitHub username.)*

### 3. Run the Project
* **Using Laragon:** Right-click inside the Laragon app window, go to **Quick Hatch** or **Menu > www**, select `php-oop-course`, and it will open automatically in your browser using a pretty URL (e.g., `http://php-oop-course.test`).
* **Using XAMPP:** Start Apache in the XAMPP Control Panel, open your browser, and navigate to `http://localhost/php-oop-course/`.
